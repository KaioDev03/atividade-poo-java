LEIA-ME — ATIVIDADE DE PROGRAMAÇÃO ORIENTADA A OBJETOS (JAVA)

Este projeto contém os seis exercícios da atividade de Programação Orientada a Objetos.

ARQUIVOS

1. Pessoa.java
   Criação de um objeto Pessoa e exibição de nome, idade e cidade.

2. Retangulo.java
   Criação de um retângulo e cálculo de sua área.

3. ContaBancaria.java
   Simulação de uma conta bancária com depósito, saque e consulta de saldo.

4. Produto.java
   Uso de encapsulamento com atributos privados e métodos getters e setters.

5. TesteFuncionarios.java
   Demonstração de herança e polimorfismo com as classes Funcionario e Gerente.

6. TesteVeiculos.java
   Demonstração de herança e sobrescrita de métodos com Veiculo, Carro e Bicicleta.

COMO EXECUTAR NO VS CODE

1. Abra a pasta que contém os arquivos Java no VS Code.
2. Verifique se o Java JDK está instalado.
3. Abra o terminal integrado em Terminal > Novo Terminal.
4. Para compilar todos os arquivos de uma vez, execute:

   javac *.java

5. Depois da compilação, execute cada exercício individualmente:

   java Pessoa
   java Retangulo
   java ContaBancaria
   java Produto
   java TesteFuncionarios
   java TesteVeiculos

OBSERVAÇÃO

Cada exercício possui seu próprio método main e deve ser executado separadamente.
Se o comando javac não for reconhecido, confira se o JDK está instalado e configurado no PATH.
